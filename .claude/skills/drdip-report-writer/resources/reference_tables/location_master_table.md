---

## HOW TO USE THIS TABLE

Use the names in the "Official Name" column in all DRDIP-II reports. Do not use variant spellings as official names.

When a user provides a variant spelling, map it to the correct official name and note the original spelling once, using this format:

> [Location originally written as "Dollo Ado" — standardised to "Dolo-Ado" per DRDIP-II location master table]

Do not silently correct variant spellings. Flag the correction inline.

For locations not on this list: flag them with [CLARIFY: this location does not appear in the DRDIP-II target area list — please confirm the correct name].

## COMBINED REFERENCE PHRASES

Use these exact phrases when referring to all DRDIP-II target areas collectively:

- "all eight DRDIP-II target woredas and city administrations"
- "the eight target woredas and city administrations of the Somali Regional State"

Do not say "eight woredas" if Kebribeyah City Administration is included — it is a city administration, not a woreda.

## NOTES ON COMMON ERRORS

| Common Error | Correct Usage |
|---|---|
| Writing "Dollo Ado" in official reports | Use "Dolo-Ado" |
| Writing "Dollo Bay" in official reports | Use "Dolo-Bay" |
| Writing "Bokhe" in official reports | Use "Bookh" |
| Writing "Danood" in official reports | Use "Danot" |
| Referring to Bokolmayo camp as "Bokolmayo Woreda" | Bokolmayo camp is in Dolo-Ado. Bokolmayo Woreda is a separate location. |
| Treating Kebribeyah Woreda and Kebribeyah City Administration as the same | They are separate administrative units. Specify which one you mean. |
| Writing "district" instead of "woreda" | Use "woreda" in all DRDIP-II reports |
