# REPORT QUALITY CHECKLIST
# drdip-report-writer v1.0
# Development Response to Displacement Impacts Project II (DRDIP-II)
# Use this checklist before submitting any DRDIP-II report.
# Tick each item. Resolve all [MISSING] and [CLARIFY] flags before submission.

---

## SECTION A — ACCURACY

- [ ] No date has been invented. All dates come from source documents or field notes.
- [ ] No budget or financial figure has been invented. All figures come from financial records.
- [ ] No participant count has been invented. All counts come from attendance sheets or registers.
- [ ] No finding has been invented. All findings come from field observations or documented evidence.
- [ ] No location or kebele name has been invented. All names come from field notes or official records.
- [ ] No activity name or result has been invented or changed without noting the correction.
- [ ] No quote has been attributed to a person who did not say it.
- [ ] No photograph description has been added for a photo not provided.
- [ ] No annex has been included that was not provided by the user.
- [ ] All figures in the report match the source data exactly. Nothing has been rounded or re-expressed.
- [ ] All contradictions in the source data are listed under ISSUES REQUIRING CLARIFICATION.
- [ ] All [MISSING] placeholders are specific and describe exactly what information is needed.
- [ ] All [CLARIFY] flags are placed where the ambiguity occurs.

---

## SECTION B — STRUCTURE

- [ ] The correct report type structure has been applied (see SKILL.md Part 7).
- [ ] The matching template was consulted before drafting.
- [ ] All required sections are present for the selected report type.
- [ ] No required section is empty without a [MISSING] flag or a justified note.
- [ ] The cover page is complete: title, report type, dates, prepared by, submission date, version, funding body, program name.
- [ ] All four components appear in quarterly progress reports.
- [ ] Only covered components appear in field mission, training, supervision, safeguards, M&E, and committee reports.
- [ ] Every recommendation in Section 10 has a corresponding entry in the Action Matrix (Section 11).
- [ ] The executive summary contains no new information not found in the body.
- [ ] The conclusion contains no new recommendations.
- [ ] Annexes are numbered sequentially and each is referenced in the body.
- [ ] No annex appears that is not referenced in the body.

---

## SECTION C — STYLE

- [ ] All sentences are 25 words or fewer.
- [ ] No em dashes used inside sentences.
- [ ] No semicolons used to join clauses.
- [ ] Active voice used throughout. Passive voice only where the actor is genuinely unknown.
- [ ] The program name is written in full on first use: "Development Response to Displacement Impacts Project II (DRDIP-II)."
- [ ] "Woreda" is used instead of "district" throughout.
- [ ] "Kebele" is used instead of "village" or "community" throughout.
- [ ] Hyphen bullets are used (not asterisks or other symbols).
- [ ] Sex disaggregation is present for participant data, or a [MISSING] flag is inserted.
- [ ] Numbers one through nine are written as words. Numbers 10 and above use numerals.
- [ ] All percentages, measurements, and monetary figures use numerals.
- [ ] All measurements include their unit.
- [ ] No hedging phrases: "it should be noted that," "it is worth mentioning," "needless to say."

---

## SECTION D — COMPLETENESS

- [ ] All [MISSING] placeholders have been resolved or flagged for the user's attention.
- [ ] All [CLARIFY] flags have been resolved or flagged for the user's attention.
- [ ] All tables are complete. No empty cells without a [MISSING] flag or dash marker.
- [ ] The action matrix includes target dates for all action items, or [MISSING] flags where dates are absent.
- [ ] Days Overdue has been calculated only where both the target date and the report date are confirmed.
- [ ] The ISSUES REQUIRING CLARIFICATION block appears before the cover page if any contradictions remain unresolved.
- [ ] All default values applied are labeled: [DEFAULT APPLIED: description — confirm before submission].

---

## FINAL CHECK

- [ ] The report has been read in full from start to finish before submission.
- [ ] The report is ready for submission without further editing.
