# MISSING INFORMATION CHECKLIST
# drdip-report-writer v1.0
# Development Response to Displacement Impacts Project II (DRDIP-II)
# Use this checklist to prepare your raw notes BEFORE invoking the drdip-report-writer skill.
# Gather all available information for your report type. Missing fields will appear as
# [MISSING: ...] placeholders in the draft. Resolve them before submission.

---

## ALL REPORT TYPES — REQUIRED FOR EVERY REPORT

| Required Field | Source | Notes |
|---|---|---|
| Report type | User decision | Must be one of the nine supported types |
| Core activity or mission | Field notes, meeting minutes, training records | The skill will ask if this is missing |
| Objective of the report | Terms of Reference, mission plan, or workplan | The skill will ask if this is missing |
| Report title | User decision | |
| Reporting period or mission dates | Calendar, field log | Start and end date |
| Prepared by | Staff records | Name, title, and organisation unit |
| Submission date | Reporting schedule | |
| Report version | User decision | Draft or Final |
| Location(s) covered | Field log, mission plan | Use exact woreda names from SKILL.md Part 4 |
| Component(s) covered | Activity records | Use exact names from SKILL.md Part 3 |
| Methodology | Mission plan, field notes | List each method used |
| Key findings | Field notes, observation records | What was observed, where, and its significance |
| Issues and challenges | Field notes, discussion notes | Obstacles to implementation |
| Recommendations | Discussion notes, mission debrief | Each must name a responsible party |
| Action items | Mission debrief, discussion notes | Each must have a target date and responsible party |
