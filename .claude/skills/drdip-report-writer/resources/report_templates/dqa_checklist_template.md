# REPORT SUBMISSION DATA QUALITY ASSURANCE (DQA) CHECKLIST
# Development Response to Displacement Impacts Project II (DRDIP-II)
# Somali Regional State

---

## HOW TO USE THIS CHECKLIST

Complete this checklist before submitting any monthly, quarterly, or annual regional progress report. The lead officer must sign against each step. Submit the signed checklist with the report or as Annex 1.

Mark each step Yes or No. If No, record the issue and corrective action in the Remarks column. Do not submit the report until all critical steps are marked Yes.

Critical steps are marked with an asterisk (*).
