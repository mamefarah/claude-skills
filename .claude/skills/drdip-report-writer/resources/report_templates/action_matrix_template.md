## STATUS DEFINITIONS

| Status | Meaning |
|---|---|
| Pending | Action has not yet been started |
| In Progress | Action has been started but not yet completed |
| Completed | Action has been fully completed (confirmed by responsible party) |
| Overdue | Target date has passed and action is not yet completed |
