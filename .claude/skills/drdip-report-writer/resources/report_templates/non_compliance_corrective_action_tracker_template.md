## HOW TO USE THIS TRACKER

Use this tracker only when compliance tracking or non-compliance follow-up has been explicitly requested. Do not include it as a mandatory section of any monthly, quarterly, or annual report. Attach it as an optional annex when needed.

This tracker records non-compliance issues flagged during implementation, the mandated corrective action, and the closure status of each issue.

Each non-compliance issue receives a unique NC number. Do not reuse NC numbers. Do not close an item without evidence of corrective action.

## CLOSURE STATUS VALUES

Use only these values in the Closure Status column:

- Open — issue has been flagged and corrective action has not started
- In Progress — corrective action is under way
- Closed — corrective action is complete and verified
- Overdue — target closure date has passed and issue is not closed

## NOTES

- Do not invent non-compliance issues. Record only issues that were formally identified during supervision, monitoring, or review.
- Do not record confidential SEA/SH cases in this tracker. Those are managed under separate confidential protocols.
- Verification evidence source must name a specific document, inspection report, or form. Do not write "verbal confirmation."
- Actual closure date is left blank until the issue is formally verified as closed.
